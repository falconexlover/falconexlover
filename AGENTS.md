# Repository instructions

## Planning

- Before non-trivial work, read `ROADMAP.md` and `STATUS.md`.
- Record an agreed public-facing plan in tracked documentation and update it with the same pull request.
- Keep draft content, local preview, published profile, and owner acceptance as separate states.
- This repository is public: never mention private repository names, clients, infrastructure, internal
  plans, credentials, personal data, or non-public contact details.
