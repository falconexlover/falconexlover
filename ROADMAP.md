# Profile roadmap

## Purpose

Maintain a concise public GitHub profile that reflects intentionally public work without exposing
private repositories, infrastructure, clients, internal plans, credentials, or personal data.

## Milestones

| Priority | Milestone | Acceptance |
|---|---|---|
| P0 | Safe public profile | README contains no private project or infrastructure details |
| P1 | Useful introduction | Public skills and interests are described accurately and concisely |
| P1 | Public portfolio links | Only explicitly approved public repositories or pages are linked |
| P2 | Periodic review | Stale claims and links are reviewed before profile updates |

Current evidence is recorded in [`STATUS.md`](STATUS.md).
